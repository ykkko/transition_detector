## Конфигурация тестов

### Файлы конфигурации
- `pytest.ini` - основная конфигурация pytest
- `requirements-dev.txt` - зависимости для разработки
- `tests/conftest.py` - общие фикстуры

### GitHub Actions
- Автоматическое тестирование для Python 3.8-3.11
- Проверка линтером flake8
- Загрузка отчетов покрытия в Codecov

### Команды для запуска

```bash
# Запуск всех тестов
python3 -m pytest tests/ -v

# Запуск с покрытием
python3 -m pytest tests/ --cov=transition_detector --cov-report=term-missing

# Запуск конкретного модуля
python3 -m pytest tests/test_utils.py -v
```
